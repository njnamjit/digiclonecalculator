# 🦖 ตารางเช็คระดับการโคลนดิจิมอน (Digimon Clone Level Checker)

เว็บไซต์สำหรับตรวจสอบและคำนวณค่าพลังจากการโคลน (Clone) ของดิจิมอนในเกมแบบอัตโนมัติ ช่วยให้ผู้เล่นสามารถเช็คได้ทันทีว่าค่าพลังที่ได้จากการโคลนนั้นแตะระดับสูงสุด (Perfect Top Clone) หรือไม่

## ✨ ฟีเจอร์หลัก (Features)

- 📊 **ตารางคำนวณค่าพลังโคลน:** แสดงผลเปรียบเทียบระดับการโคลนและค่าพลัง TOP แบบเรียลไทม์
- 🎨 **ดีไซน์ทันสมัย:** มาพร้อมเอฟเฟกต์ Logo Animation และวิดีโอพื้นหลังเพิ่มความสวยงาม
- 📱 **Responsive Design:** รองรับการแสดงผลทั้งบนคอมพิวเตอร์และอุปกรณ์เคลื่อนที่
